# OTINER

**OTINER** — پنل ۹ پد ساند افکت برای **Adobe Premiere Pro 2024، ویندوز و macOS** با زرد خالص و تم روشن/تیره.

نسخهٔ **۱٫۳**: ظاهر مینیمال بر اساس مرجع OtinerPresetStudio، تم روشن/تیره، جستجو و فیلتر صداها. خطای `getAudioChannelMapping() is not a function` با پشتیبانی از حالت آبجکت و تابع برطرف شده است. [دانلود نسخهٔ جدید](https://github.com/adib-rahamani-dev/SoundPrime/releases/latest)



## نسخهٔ مک — Intel و Apple Silicon

بستهٔ **OTINER-1.3.0-macOS-Universal.zip** را از [Releases](https://github.com/adib-rahamani-dev/SoundPrime/releases) بگیرید، Extract کنید و با پریمیر بسته، **Install.command** را باز کنید. هدف macOS 12+ و Premiere 24.x است؛ بسته شامل باینری هر دو معماری است. میان‌برها با **Cmd+Shift+1…9** شروع می‌شوند. [راهنمای نصب مک، Gatekeeper، فایل KYS و حذف](docs/macOS.md)

این نسخه امضای Developer ID و notarization ندارد. ساخت Universal و تست‌های CLI مک در CI انجام می‌شوند؛ **درج واقعی صدا و میان‌بر داخل پریمیرِ مک هنوز تأیید نشده‌اند**.

## نصب خودکار ویندوز

۱. پروژه را از **Code → Download ZIP** دانلود و کامل Extract کنید، یا بستهٔ آماده را از بخش **Releases** یا **Actions → Windows and macOS packages → Artifacts** بگیرید.

۲. پریمیر را ببندید و روی **Install.cmd** دوبار کلیک کنید. دسترسی ادمین، Node.js و دانلود وابستگی لازم نیست. نصب‌کننده همراه میان‌بر را با کامپایلر .NET Framework موجود در ویندوز می‌سازد و پنل را برای کاربر جاری نصب می‌کند.

۳. پریمیر ۲۰۲۴ را باز کنید و از **Window → Extensions → OTINER** پنل را باز و در محیط کاری Dock کنید. پنل باید برای کار کردن میان‌برها باز بماند.

این نسخهٔ CEP بدون امضای تجاری است؛ نصب‌کننده مقدار `PlayerDebugMode=1` را در `HKCU\Software\Adobe\CSXS.11` تنظیم می‌کند تا پریمیر پنل را بارگذاری کند. این تنظیم برای افزونه‌های بدون امضای همان CEP runtime نیز اعمال می‌شود. مقدار قبلی ثبت می‌شود و Uninstall.cmd آن را در صورتی که همچنان مقدار نصب‌شده باشد برمی‌گرداند. هیچ تنظیم فایروال، آنتی‌ویروس یا اجرای خودکار ویندوز تغییر نمی‌کند.

## استفاده

- تا ۹ فایل صوتی را با «افزودن صدا» یا Drag & Drop روی پدها انتخاب کنید. از WAV، MP3، AIFF، M4A، AAC، FLAC و OGG می‌توان استفاده کرد؛ پشتیبانی دقیق کدک در پریمیر و پیش‌شنوی CEP ممکن است متفاوت باشد. WAV پیشنهاد می‌شود.
- روی موج یا دکمهٔ «پریویو» برای پیش‌شنوی بزنید. پخش‌کننده دارای مکث، توقف و جابه‌جایی داخل صداست. موج هر صدا از نمونه‌های واقعی فایل ساخته می‌شود؛ برای فایل بزرگ‌تر از ۸۰ مگابایت یا کدک غیرقابل رمزگشایی در CEP، موج ساخته نمی‌شود. VOL فقط صدای پیش‌شنوی را تغییر می‌دهد.
- روی سه‌نقطه یا میان‌بر پد بزنید، نام صدا را تغییر دهید، سپس روی کادر میان‌بر کلیک کنید و کلید دلخواه را بزنید. میان‌بر باید شامل Ctrl، Alt یا Shift همراه حرف انگلیسی، عدد ردیف بالا یا F1 تا F12 باشد. کلیدها بر اساس جای فیزیکی صفحه‌کلید شناسایی می‌شوند.
- برای انتخاب اسم، مستقیم روی نام پد کلیک کنید. نام دلخواه حتی پیش از انتخاب فایل قابل ذخیره است و روی پد و پخش‌کننده نمایش داده می‌شود. تغییر نام فایل اصلی را جابه‌جا یا تغییرنام نمی‌دهد.
- یک سکانس باز کنید، ترک صوتی مناسب را از TARGET انتخاب کنید، نشانگر را جابه‌جا کنید و روی دکمهٔ «درج» یا میان‌برش بزنید. میان‌برهای پیش‌فرض Ctrl+Shift+1 تا Ctrl+Shift+9 هستند و قابل تغییرند.
- فایل‌ها در Bin به نام OTINER وارد می‌شوند؛ کلیپ موجود دوباره استفاده می‌شود. درج از In تا Out منبع انجام می‌شود. اگر بازهٔ مقصد اشغال یا ترک قفل باشد، عملیات متوقف می‌شود. درج Ripple ندارد. برای Undo از امکانات خود پریمیر استفاده کنید.
- درج امن محدود به منبعی با یک کلیپ مونو یا استریو است؛ نگاشت‌های چندکلیپی و Surround رد می‌شوند تا ترک‌های مجاور تحت تأثیر قرار نگیرند. بررسی فضای خالی تا انتهای فریم آخر صدا انجام می‌شود.
- «ذخیره بانک» تنظیمات را JSON می‌کند و «بازیابی بانک» آن را برمی‌گرداند. تنظیمات به‌صورت خودکار نیز ذخیره می‌شوند. بانک شامل مسیر فایل‌هاست؛ خود صداها کپی نمی‌شوند. پس از جابه‌جایی فایل، از تنظیمات پد دوباره آن را انتخاب کنید.

## بررسی تداخل میان‌بر

سه بررسی مجزا انجام می‌شود:

۱. **داخل بانک:** میان‌بر تکراری بین پدها هنگام ذخیره رد می‌شود.

۲. **ویندوز:** همراه محلی با `RegisterHotKey` اشغال بودن میان‌بر را بررسی می‌کند و نتیجه را روی پد نشان می‌دهد. کلید اشغال‌شده اجرا نمی‌شود. فقط هنگام فوکوس روی پردازش Adobe Premiere Pro کلیدها ثبت می‌شوند؛ با خروج از فوکوس آزاد می‌شوند. ثبت ویندوزی فهرست فرمان‌های داخلی پریمیر را نشان نمی‌دهد.

۳. **پریمیر:** فایل **KYS فعال خودتان** را با «بررسی میان‌بر پریمیر» انتخاب کنید. از Edit → Keyboard Shortcuts → Save As یک تنظیم ذخیره کنید؛ فایل معمولاً در `Documents\Adobe\Premiere Pro\24.0\Profile-…\Win` قرار دارد. همهٔ Contextهای فایل بررسی می‌شوند، بنابراین ممکن است تداخل یک پنل دیگر هم گزارش شود. میان‌برهای متداخل با این فایل غیرفعال می‌شوند. تا انتخاب KYS، وضعیت «KYS بررسی نشده» است؛ آزاد بودن در ویندوز به معنی آزاد بودن در پریمیر نیست. بعد از تغییر تنظیمات کیبورد پریمیر، فایل را دوباره وارد کنید.

هنگام ضبط میان‌بر، کلیدها موقتاً آزاد می‌شوند. پنل و همراه با فایل‌های موقت محلی ارتباط دارند؛ اینترنت، ارسال کلید، سرویس پس‌زمینهٔ دائمی یا Hook کیبورد وجود ندارد. اگر پنل پاسخ ندهد، همراه پس از ۱۵ ثانیه بدون Heartbeat بسته می‌شود. همراه میان‌بر باید در زمان استفاده در حال اجرا باشد.

## حذف، تنظیمات و رفع مشکل

پریمیر را ببندید و **Uninstall.cmd** را اجرا کنید. صداها، بانک و نسخهٔ پشتیبان تنظیمات حفظ می‌شوند.

- محل نصب: `%APPDATA%\Adobe\CEP\extensions\ir.oteener.soundprime`
- بانک و نسخهٔ پشتیبان: `%APPDATA%\Oteener\SoundPrime\bank.json` و `bank.json.bak`
- نسخهٔ قبلی پنل در نصب مجدد: `%APPDATA%\Oteener\SoundPrime\backups`
- اگر پنل دیده نشد، نسخهٔ پریمیر را بررسی و یک بار کامل بسته و باز کنید. محدودهٔ manifest عمداً 24.x است؛ نسخه‌های جدید UXP به پیاده‌سازی جدا نیاز دارند.
- «همراه قطع است»: پریمیر را ببندید و نصب‌کننده را دوباره اجرا کنید. خطای کامپایل یعنی .NET Framework 4.x ویندوز در دسترس نیست.
- برای اجرای میان‌برها، پریمیر باید فوکوس داشته باشد؛ پنجرهٔ تنظیمات و انتخاب فایل را ببندید. در صورت تداخل، کلید دیگری انتخاب کنید.
- باز کردن `extension/index.html` در مرورگر فقط پیش‌نمایش ظاهر و پیش‌شنوی است؛ درج در تایم‌لاین و بررسی ویندوزی به CEP نیاز دارند.

## توسعه و بررسی

کد پنل بدون وابستگی JavaScript و بدون مرحلهٔ bundle است. به Node.js 18+ برای تست و Windows .NET Framework 4.x برای ساخت نیاز دارید:

```powershell
npm test
npm run build
npm run install:plugin
```

قبل از اجرای تست‌ها، یک بار `npm ci` اجرا کنید. وابستگی jsdom فقط برای تست آفلاین رابط است؛ خود پلاگین به نصب هیچ بسته‌ای نیاز ندارد. [تغییرات نسخهٔ ۱٫۱](docs/CHANGELOG.md)

تست واقعی ثبت کلید در ویندوز: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/verify-native.ps1` پس از build. تست اختیاری رابط با نصب Playwright و مرورگر آن: `node scripts/verify-ui.cjs`. مسیر ماژول و مرورگر موجود را می‌توان با `SOUNDPRIME_PLAYWRIGHT` و `SOUNDPRIME_BROWSER` تعیین کرد. تست رابط فایل‌های صوتی مصنوعی در حافظه می‌سازد و اسکرین‌شات خروجی در `artifacts` می‌گذارد.

بستهٔ خروجی: `dist/OTINER-1.3.0-Windows.zip`. روی مک، `npm run build:mac` فایل `dist/OTINER-1.3.0-macOS-Universal.zip` را می‌سازد. اکشن گیت‌هاب هر دو بسته را تولید می‌کند. تست‌های خودکار شامل تداخل بانک، خواندن KYS، اعتبارسنجی بازیابی و قراردادهای درج در میزبان شبیه‌سازی‌شده‌اند؛ جای تست واقعی تدوین با پریمیر را نمی‌گیرند.

ساختار: `extension/js` پنل و داده‌ها، `extension/jsx` ارتباط ExtendScript، `extension/native` همراه C# و `installer` نصب و حذف. فایل صوتی کاربر، تنظیمات محلی و باینری خروجی وارد Git نمی‌شوند.
